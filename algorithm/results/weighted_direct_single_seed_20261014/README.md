# 当前直送方案与加权总分：240 秒单种子配对

本批只比较运行前 main `61488fe` 的公共默认算法和其加权目标适配版，
不比较其他历史方法。未提交的 `weighted_direct_240s_20261014` 是另一批既有数据，
本批不读取其结果，也不混算成绩。

## 冻结协议

官方完整 200 项任务、8 架无人机、载荷容量 2、每机累计 K=25、速度 0.9 km/min。
所有机从原点出发，无中继、无预部署，先取后送，完成全部任务，不计末单之后返航。
共同种子为 `2026101451`。只运行 `current_lex` 和 `current_weighted` 各一次，
按此顺序串行执行；不择优重跑，不追加其他种子、场景或权重。

每方案端到端上限 240 秒，包括输入读取、同样的词典序初解构造、搜索、
完整核验及解写出，不含 Python 导入。搜索预算扣除实测构造时间和 1 秒收尾预留，
因此实际搜索时间小于 240 秒。计时期间不运行测试或其他求解实验。
主机不是独占环境；单种子和墙钟截断不能支持统计显著性、稳定性或速度因果结论。

两方案各自重建共同初解并核对路线指纹：初解为 108 项逾期、
4464.183540734935 分钟总逾期、775.7731679286865 公里航程。
加权适配只在初解构造之后启用，保证构造与起始路线一致。

## 加权目标及其含义

```text
J = 0.50 × 逾期任务数 / 200
  + 0.25 × 总逾期分钟 / 4464.183540734935
  + 0.25 × 总航程公里 / 775.7731679286865
```

权重和尺度均在计时前冻结，不由终值选择。尺度来自共同初解，不在搜索中更新。
每多一项逾期使 J 增加 0.0025，可单独由 44.6418354 分钟总逾期改善
或 7.75773168 公里航程下降抵消。多项变化按同一线性总和计算。
这是真实有限交换率，允许少数任务时效下降；J 是研究目标，不是题目官方评分。

原题直接关注按时任务数/率、航程与可控求解时间；逾期数和按时率是同一服务维度。
总逾期分钟是本项目增加的次级目标。报告优先显示物理指标，再展示共同 J 的分解，
不以 J 较低直接推断题目的服务优先要求获胜。

## 实现范围

生产源码和公共默认保持原词典序。实验入口冻结当前源码，再对候选源码进行
有计数断言的 AST 适配；原版源码、实际适配源码分别存于 `sources/`。
加权规则贯穿整体 Score 比较、插入与修复排序、regret、退火增量、最优解保留，
以及已有相邻微调与末端强化。等 J 时用原物理三元组作确定性回退；regret 的
四项回退完整保留，缺少备选的无穷优先级也统一适配。

既有算子池保留，`worst_lex` 随 Score 改为加权损失；静态
deadline/slack/risk/assignment_destroy 规则保留。退火温度端点及降温参数不调，
但接受增量已改成 J 的变化量，因此差异来自整个一致目标的搜索过程。
所有结构约束及原始三指标的规范评价保持原物理含义。
单种子试验不作为替换公共默认的依据。
