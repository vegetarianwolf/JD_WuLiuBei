# 本轮文献与实现判断

检索日期：2026-10-13（Asia/Shanghai）。使用用户指定的 paper-lookup Skill；定向查询 3 个学术 API（Crossref、OpenAlex、arXiv），不追求穷尽文献。8 次 API 请求及 1 次出版商页面读取成功；首次沙箱内两次请求因 DNS 失败，获准联网后恢复。所有实际参数、HTTP 状态、返回条数与文件 SHA-256 见 `literature.json`。

## 与原题对齐

原题要求先保证尽可能多的订单按时，再缩短完成全部任务的总航程，并控制计算时长。官方条件为 200 任务、8 架无人机、每机累计最多 25 项、载荷最多 2 件、速度 0.9 km/min、不计末单后返航；单机验证使用 25 任务。项目沿用 `(逾期数, 总逾期分钟, 航程)` 的三级词典序，总逾期分钟是项目次级约定，报告不能写成原题单列指标。

历史已覆盖跨机 regret、位置回退、组合 regret、截止期边界破坏、第一目标奖励及 2%–5% 小邻域。已有短长测反转和中测退化，不能重复这些变体或把短测均值写成成功。本轮隔离两个新候选，不组合使用，完整解由独立评价器复算。

## A：DIRECT 插入候选缓存——本项目实现优化

Gschwind 与 Drexl 的 DARP 工作把插入可行性计算作为 ALNS 修复热路径进行摊还常数时间优化；已核实 Crossref 摘要，而未读取全文。[论文 DOI](https://doi.org/10.1287/trsc.2018.0837)

本轮缓存不可冒称其原算法：在同次求解内，以完整不变路线、任务/腿、无人机起点、候选位置上限和返回数量等语义作为键，复用确定性插入候选；设容量上限与淘汰策略。先用固定迭代确认路线、完整得分、随机决策与无时钟轨迹一致，再测同秒数的吞吐和题目指标。历史已有 scored-bundle 缓存净亏，故本轮必须保存命中率、真实耗时与回退情况，不因“用了缓存”就认定提速。

## B：按预算进度的几何冷却——原文公式的项目适配

实际读取 Santini、Ropke 与 Hvattum 出版商全文的第 2 节及第 3.5 节。其指数 SA 将起止温度连接到 K 次迭代预算：每步乘 `(T_end/T_start)^(1/K)`；原文也比较不同接受准则，支持将接受策略作为可单独测试的机制。[论文全文](https://link.springer.com/article/10.1007/s10732-018-9377-x)

当前实现 `T_start=.03`、`T_end=.0005`、每轮乘 `.995`，算术上 817 次完整迭代后达到最低温度，与最终迭代数或时限无关。候选保持起止温度及现有词典序接受增量，使用 `T=T_start*(T_end/T_start)^p`。固定轮数时 p 为迭代进度；墙钟时 p 为实际搜索时间/可用搜索时间，构造时间不得再次计入搜索时长。墙钟适配是本项目推演，原文没有保证它在本赛题上更优。

低温在基线中帮助后期细化，高温也可能消耗预算；修改会改变搜索轨迹，须每个种子独立比较，不应用均值掩盖第一目标退化。完整词典序 incumbent 始终保留。

## 暂不实现的后续线索

Christiaens 与 Vanden Berghe 的 SISRs 摘要提供相邻串移除和带随机跳过的贪心插入。可研究跨多条邻近路线的成对串移除，使满载集群同时释放多个任务槽；移除时必须保留取送整体语义。当前 `route_segment` 已是单路线片段移除，因此未来方案要明确新增的跨路线部分。[论文 DOI](https://doi.org/10.1287/trsc.2019.0914) arXiv 精确标题检索为 0，不能据此声称没有论文；本条仅摘要级线索。

Burke 与 Bykov 的 Late Acceptance 工作已核实题名、作者、年份和 DOI，但原论文全文未读；Santini 比较文中的第 3.3 节提供环形历史接受规则，可作为未来替代退火的独立试验。[原论文 DOI](https://doi.org/10.1016/j.ejor.2016.07.012)
