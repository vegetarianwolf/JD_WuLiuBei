# 相邻访问微调的方法依据

本批复用第二批已核验的 Curtois 等（2018）PDPTW 出版商全文阅读，不重复联网检索。
原 API 参数、HTTP 状态、页码、网页核实指纹及失败边界见
[第二批检索证据](../../iteration2/literature/literature.json)。本批 `literature.json`
绑定该文件 SHA-256，新增 API 调用为 0，不能把复用文献计作新的检索样本。

原文 M3 交换不同路线之间的完整取送任务对，并采用先改善式探索。本批在单条路线中
定期尝试相邻访问点交换，计算量受限；这是项目新设计，不是原文 M3 或完整 VND。
不将原文在其他实例上的性能移植到本题。

相邻两点属于不同任务时，交换不会跨过任一任务的配对节点，因此保持先取后送；
只需检查交换后第一个事件的载荷，第二个事件之后的载荷曲线不变。
路线完整评分严格改善才采用，最终历史最优仍由独立完整全局评分确认。
两项事实只支持合法性和计算量限制，不保证相同时间下最终成绩更好。

本批使用新的配对种子和完整路线，不合并之前三项失败候选的胜负。
软件方法引用同时保留已在首批 arXiv 核实的
[Scientific Agent Skills](https://arxiv.org/abs/2609.00065)。
