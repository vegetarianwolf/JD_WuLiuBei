# 三机移动拼单模型契约 v1

本契约在该分支首个官方任务 START 前保存。它是新的连续会合扩展，不回写此前
四固定站缓存、双机互换或单源移动接货模型，也不表示已经取得性能优势。

## 不变的输入与资源

官方200任务、8机、容量2、0.9km/min、软截止期、零处理时间、开放路线及
当前冻结加权J不变。final-K仍按最终配送责任计，每机25项；入站运输不额外
占final-K，这是既有论文扩展口径。所有物理起点、原四站、原注册腿和任务坐标
保持不变。全部任务静态已知，不引入额外订单、预测样本或免费调位。

输入限定为纯DIRECT欧氏解。原A的任务i、原B的j由第三机C最终共同配送；
原C的k1/k2整单DIRECT分别补偿A/B，三机最终配额保持。其他任务的所有权与
相对事件顺序保持。每项中继仅一次，三机不同，四项任务不同。

## 新会合点的真实物理含义

一次候选至多追加一个R和i/j各一套IN/OUT腿。R是两次真实空中接触的共同
坐标，不提供设施、地面存货、额外飞机或新的起点。只把最后采用的点及四条腿
加入输出Problem，不把试过的点作为额外资源保留。所有飞行、空载等待和持货
等待都计入。

源机A/B分别持货飞到R。C必须空载先到，且早于两台源机。C按源机实际到达
先后逐件接货：先持一件等待另一件，再持两件飞过正距离后交付。每件drop与
take发生在同一瞬间，移动点地面缓存为0；每台源机在自己的接触完成后可以
离开。两次接触不要求三台飞机在后一瞬间同时留在R。

如C晚于任一源机、接货事件顺序与源机到达相反、原四站/起点改变、缺腿、
超载、额度未恢复或共同载货距离为0，候选均拒绝。原固定站的异步缓存提案
可作为明确标注的raw构造证据，不把它称为新的移动交接。

## 固定布局的时序与安全界

各机到新接触前的最后坐标/时刻记作u_q/t_q，速度v；此分支前缀不依赖R。
定义a_q(R)=t_q+||u_q−R||/v。接收机先到的条件为
`a_C <= min(a_A,a_B)`。只在这个固定、无更早可变交接的布局中，全空间存在
可行点当且仅当
`t_C <= t_A+||u_A-u_C||/v`且` t_C <= t_B+||u_B-u_C||/v`。
两个相对提前量都在R=u_C达到上限；候选域须包含这个原路线坐标。

C首次/第二次take分别发生于min(a_A,a_B)/max(a_A,a_B)，空载/持一件等待
分别为`min−a_C`/`max−min`。A/B后继时刻从自己的到达计起，C后继从max计起。
全路线manual分数必须与完整全局DAG分数核对，期限仍是软目标，椭圆仅作种子。

对每机R后第一个固定坐标v_q及之后任务k的固定时间偏移c_qk，安全下界为：

- A后任务：`max(t_A+d(u_A,v_A)/v, t_C+d(u_C,v_A)/v)+c_Ak`；B同理。
- C后任务：`max(t_A+d(u_A,v_C)/v, t_B+d(u_B,v_C)/v, t_C+d(u_C,v_C)/v)+c_Ck`。
- 航程：固定部分加最多六端点u_q/v_q的最大完美匹配距离和；开放尾缺端点时
  使用最大近完美匹配，未配端点的非负距离忽略。

各分量的最优点未必一致，以上是乐观界，不是可实现分数。数值剪枝须保守弱化
时钟/距离，再应用既有期限容差。几何中位数是候选点，不能充当距离下界。

接收机先到区域未必凸；以u_C为中心沿每条射线可行段单调，允许二分生成
经过实际约束复核的点。投影、有限pattern或椭圆种子没有找到改善，不等于
证明整个算法或全部移动会合空间没有更优方案。

## 比较与审计

DIRECT控制使用同原任务、物理起点、目标、总预算、宏动作selector和最终责任
映射，完整取送i/j。每臂自己的候选计算成本都计入，提前穷尽如实记录。所有
开发checkpoint追加试验都明确标记为机制诊断；胜过受限宏DIRECT不等于胜过
强DIRECT算法，更不等于完整同预算性能胜出。

新独立审计重建全部实际时钟、飞行、0/1/2载荷等待、零缓存、角色及共载距离，
绑定每个已保存完整候选的点、腿、事件和物理元数据。原责任/其他任务继承
仅在提供真实、source-bound输入路线时核验，不能从站点表猜测或构造假baseline。
