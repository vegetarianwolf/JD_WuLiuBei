# 移动重新配载：补偿插入前的完整方案下界（v1）

日期：2026-10-15。本文为针对本仓库受限邻域的自行推导；不是文献结论，也不是正式性能实验。当前 `source_frontier` 开发只增加候选多样性和严格缓存，**没有据本文新增剪枝**。

## 适用范围

原输入是完整纯 DIRECT；保留所有原始起点、机队、速度和任务。固定一组不同任务 `i,j,k1,k2`、不同飞机 `A,B,C`，原责任为 `i:A,j:B,k1:C,k2:C`。先从原路线移除这四项完整任务，再原子加入 `A:IN_i`、`B:IN_j`、`C:OUT_i,OUT_j`。讨论的 partial 仅缺 `k1,k2`，随后仅将完整 DIRECT `k1` 插入 A、`k2` 插入 B。

本结论要求：

- 原有事件的飞机和相对顺序保持。补偿任务只能新增 pickup/delivery，不能删除、移动或交换已有事件。C 的两个接货正事件可为适应真实源到达顺序而互换；二者相邻、同一坐标、处理时间为零，二者之间没有任何其他事件。C 的两项选中最终交付及其他原后继事件全部位于第二次接货之后。
- 距离为固定欧氏距离，满足三角不等式；各机等速正速度；任务没有 release time；handling 为零。原有任务交付期限、固定 homes、起始时刻、资源不变。
- partial 与完成路线均保持既有完整腿的 coverage；完成方案另通过完整任务覆盖、容量 C2、最终责任 K、DAG 和真实物理校验。partial 不必已经满足移动接收机先到约束。
- 此处移动分支只允许 C 空载先到，`arrival_C <= min(arrival_A,arrival_B)`；每源机到达即与 C 接触，drop 与 take 同时，源机不额外等待，地面缓存为零。没有其他活动中继依赖。
- 加权目标使用完整题目冻结的三项正权重和尺度；官方 `200` 始终是全题 N 的尺度，不能换成 partial 的 present 数。数值比较使用保守下界和安全误差余量。

这不是任意 ALNS destroy/repair 邻域的结论，也不适用于后续允许改变原事件顺序、改变 homes、非度量矩阵或让源机先到后等待的未实现模型。原四个固定 H 的缓存中继方案继续作为单独物理基线；不能使用移动 receiver-first 约束排除这些基线。

## 固定 R 的单调性

固定任一会合点 R，比较完成方案与删除两项补偿 P/D 后的原 partial 事件序列。对每一原相邻事件边，完成路线可能在其间经过若干新点。三角不等式保证这段路径长度不小于原直接边；原起点至第一个原事件同理。因此每机总距离不减。零 handling、无 release 和无其他活动中继时，每个源机的原事件到达时刻不减。

记两源 drop 到达为 `a_A,a_B`，C 至原接货块的到达为 `a_C`。C 的 prefix 未插入补偿，故 `a_C` 不变。两个 co-located take 结束时刻为

`T = max(a_A,a_B,a_C)`。

source arrival 分别不减，故 T 不减；其后的所有原 C 事件沿保留的固定顺序传播，时刻同样不减。两源先后顺序反转不会改变 max，也不改变接货块的路径长度。对于物理可行的完成方案，C 按真实早源、晚源顺序接货，两个 take 分别等于对应 source drop，且第二次 take 为 `max(a_A,a_B)`。这也说明为什么必须排除两个 take 之间的 native 事件及选中交付。

如果 partial 在该 R 无法满足 receiver-first，仍可将“不加源机等待、只按 drop→take 传播”的固定点时刻作为**松弛时刻**：它没有假装是零缓存可执行方案，但其原交付时刻仍不晚于上述合法完成方案。不能把松弛时刻称为物理可行中继方案。

## 不限制 partial 可行 R 集合的全域分量下界

以下量均从 partial 的原事件序列定义，不能取自另一个 state：

- `u_q,t_q`：A、B 在各自 IN drop 前、C 在首次 OUT take 前的最后一个原固定点及其无等待 prefix 时长；没有前置事件时使用原 home 与零。
- `v_q`：各机会合后第一个原固定事件点；源机可无后继，此时跳过该支。
- `c_qk`：从 `v_q` 到原任务 k 交付点，沿保留 suffix 的累计固定飞行时长，起点 `v_q` 本身不重复计程。

对于任意保序补偿插入和任意合法 R，完成方案的源 drop 满足

`drop_A >= t_A + d(u_A,R)/v`，`drop_B >= t_B + d(u_B,R)/v`。

这是“保留 prefix 原事件、允许在其间插入点”的三角路径界，不要求完成方案的紧邻 R 前一点仍是 `u_A/u_B`。由于完整移动方案必须 receiver-first，亦有

`drop_A >= t_C + d(u_C,R)/v`，`drop_B >= t_C + d(u_C,R)/v`。

因此源机原 suffix 交付的全 R 下界为

`T_Ak >= max(t_A+d(u_A,v_A)/v, t_C+d(u_C,v_A)/v) + c_Ak`，

`T_Bk >= max(t_B+d(u_B,v_B)/v, t_C+d(u_C,v_B)/v) + c_Bk`。

C 的原 suffix 交付满足

`T_Ck >= max(q in {A,B,C}: t_q+d(u_q,v_C)/v) + c_Ck`。

各 prefix 原交付直接使用其 partial 无等待时刻；其他飞机的原交付与原路线不变。不同交付下界可以由不同 R 取得最小值，**无需同时可达，不能称为可实现的 score**。

距离方面，将 partial 的三条 `u_q→R→v_q` 可变路径从其全路线距离中分离为固定 `D_const`。任意完成方案满足

`D_full >= D_partial(R) = D_const + sum_q d(u_q,R) + sum_{q:v_q exists} d(R,v_q)`。

终端集合为三个 u 与存在的 v。任取不相交终端配对，利用每对 `d(x,y)<=d(x,R)+d(R,y)`，得到星形长度下界。取所有完美匹配的最大配对和；奇数个终端取所有少留一个终端的近完美匹配的最大值，仍是有效下界。几何中位数迭代所得的目标值是某个可行 R 的星形代价上界，**不能用作全域下界**。

将以上每项原任务时刻下界记为 `ell_k`，令原题有效迟到函数为 `late(x)=x` 当 `x>1e-9 min`，否则为零。使用足够保守的时刻下界后，

`N_LB = sum_k 1[ell_k-deadline_k > 1e-9]`，

`L_LB = sum_k late(ell_k-deadline_k)`，

两项只对 present 原任务求和。缺少的 k1/k2 在完成方案中的 N/L 贡献非负，故取零仍是下界。与距离下界组合，固定正权重、固定 full scales 得到 `J_LB <= J_full`。N、L、D 三项均是分量下界，也可支持原冻结物理 tie-break，但实现必须处理浮点余量，不应用不稳定相等判定拒绝可能改进。

目前 helper 使用时钟 `1e-8 min`、距离 `1e-10 km` 的保守余量；新实现若改变累计顺序、输入尺度或比较逻辑，应重新核验误差界和 `1e-9 min` 迟到断点。不能把一项不保守的“近似最优 score”代入本证明。

## 严禁用 partial receiver-first False 作完成不可行证书

对于**固定 prefix**，receiver-first 在整个 R 平面可行当且仅当

`t_C <= min(t_A+d(u_A,u_C)/v, t_B+d(u_B,u_C)/v)`。

但补偿插入会增大源机时长并可能改变紧邻会合的点，因此 partial 的可行 R 集合不是完成方案可行集合的超集。不得先将 R 限制到 partial receiver-first 区域再最小化并将其当作所有完成的界，更不能在该区域为空时剪枝。上一节 clock 下界直接从**最终完成方案**的 receiver-first 必要条件推出，不依赖 partial 已可行。

## 真实完整小例：补偿使全域不可能的 partial 恢复可行

单位为 km/min；v=1，C2，K3；三机 homes 为 `A=(0,0),B=(0,0),C=(-10,0)`。七项任务均 deadline=100：

| task | P | D | 原最终责任 |
|---|---|---|---|
| 1=i | (0,0) | (10,0) | A |
| 2=j | (0,0) | (11,0) | B |
| 3=k1 | (5,0) | (0,0) | C |
| 4=k2 | (5,0) | (0,0) | C |
| 5 | (0,0) | (0,0) | A |
| 6 | (0,0) | (0,0) | B |
| 7 | (-10,0) | (0,0) | C |

完整原 DIRECT 路线为 `A:[+5,-5,+1,-1]`、`B:[+6,-6,+2,-2]`、`C:[+7,-7,+3,+4,-3,-4]`，所有任务覆盖一次，最终责任数 `(2,2,3)`，容量不超过 2。

取 R=(0,0)，IN/OUT 腿编号分别为任务1的 `101/102`、任务2的 `201/202`。缺补偿的 atomic partial：

`A:[+5,-5,+101,-101]`

`B:[+6,-6,+201,-201]`

`C:[+7,-7,+102,+202,-102,-202]`

其 `u_A=u_B=u_C=(0,0)`、`t_A=t_B=0,t_C=10`。因此对任意 R，C 的到达永远比两个源晚 10 min；该 partial 的 receiver-first **全域不可能**。

现在只插入两个完整补偿 DIRECT，不改任何已有事件顺序：

`A:[+5,-5,+101,+3,-3,-101]`

`B:[+6,-6,+201,+4,-4,-201]`

`C:[+7,-7,+102,+202,-102,-202]`

A/B 持 IN 货时各取另一件补偿货，载荷 `1→2→1`，经过 `(0→5→0)`，到 R 时均为 10 min。C 在 10 min 到 R，空载接两件，load `0→1→2`，每件 drop/take 均为 10，零地面缓存；两选中货共同飞 `(0→10)` 正距离 10 km 后分别交付。补偿完整直送，原 native 事件所有权与相对顺序保留，最终责任仍 `(2,2,3)`。

本例用标准库独立最长路 DAG 小回放验证，无任何生产优化器调用。结果：partial coverage `{1,2,5,6,7}`，松弛 D=21；完成 coverage `{1,...,7}`，D=41；完成交付时刻 `5:0,6:0,7:10,3:10,4:10,1:20,2:21`；两次 drop/take 都为10。全部期限100，N=L=0。它仅证明“补偿可以修复先到条件”和下界边界；**不证明中继性能优于 DIRECT**。七任务 toy 的责任分布不冒充官方 200任务、8机、每机25 的实验。

## 后续实现前的 tiny 检查建议

1. 验证上述 partial receiver-first False、完成 True，禁止用 False 提前删除该家庭。
2. 在保序插入前后对多个固定 R 独立回放，逐原任务比较 delivery clocks 与 D；包括两个源到达先后反转、补偿插在原 prefix/suffix、源无后继、零长度事件及容量边界。
3. 独立确认 R 星形匹配和每任务 clock LB 不大于全部真实完成值；缺补偿贡献取零；归一化始终 full scales。
4. 在 deadline±1e-9、±1e-8 的时刻附近核验 N/L 与安全 margin；禁止未完成 full check 或超 deadline 候选被采用。
5. 将“完成方案分量下界”与“partial自身 receiver-first 可行性”“有限种子找到的代价”“原固定 H 缓存基线”分开记录。正式采用前仍须完整独立 source/quota/native/物理审计。
