## 改变下一行动的证据

本轮排除了“native 完全不能换机”和“只要补回新增逾期普通任务就能改善该 raw”的简单解释。最优单组在 D_native 空时已经 L/D/J 全劣；额外中继又把原准时154变成受保护迟到任务。当前 native 只能围绕既有 group 的计划、角色、H 和 selected 顺序调整普通任务。

下一实质假设是：允许一个已有完整 relay group 连同其真实 source/receiver 因果前缀原生任务，一次重新预约或替换后再按完整全机 J 比较，而非继续扩大 focus cap 或只换损伤任务。该交换/重预约本身并非首次提出；需要与已有有限重排方法区别，并保持所有任务、真实 K/C2/交接等待及独立强 DIRECT 控制。本诊断不实现或注册新一轮，也不保证该假设会改善。

目前没有“中继远胜直送”的证据。040 是单个历史 checkpoint 的付费机制探查；有限候选失败不证明所有中继结构全局无效。原始已通过审计、三个独立 post 完整重放、其余保存实体与未保存探测的证明边界分别保留在同名 JSON 中。
