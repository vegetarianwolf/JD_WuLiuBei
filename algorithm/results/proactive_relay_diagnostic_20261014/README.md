# 跨机接力机制研究：强直送 checkpoint 上的有界诊断

目标仍是取得经同预算对照验证的大幅中继收益，目前尚未达到。
这里的诊断使用此前已完成 240 秒搜索的预部署直送强解，再增加候选搜索预算。
它用于判断新邻域能否改变强解，**不是**与 240 秒直送的公平性能比较。
新方法如有希望，将在另外的 fresh screen 批次从共同初解开始比较，随后用新种子验证。
