# 跨机接力机制研究：强直送 checkpoint 上的有界诊断

目标仍是取得经同预算对照验证的大幅中继收益，目前尚未达到。
这里的诊断使用此前已完成 240 秒搜索的预部署直送强解，再增加候选搜索预算。
它用于判断新邻域能否改变强解，**不是**与 240 秒直送的公平性能比较。
新方法如有希望，将在另外的 fresh screen 批次从共同初解开始比较，随后用新种子验证。

## 中继冷构造诊断

`batch004` 在同一strong checkpoint上比较同构造关闭／允许中继，固定
`2026101491`，各20秒上限，实际0.587／10.336秒。两臂各生成6个完整提案，
全部不及原强解，终局保护返回原始141按时、579.231417km、J0.434681316。
DIRECT构造最好为102逾期、777.544650km、J0.721277；中继构造最好为104逾期、
793.153713km、J0.748682，含22项真实跨机。中继排序偏好更强的构造会产生
176–199项跨机，但成绩更差；排序credit未进入真实目标或最终保留判断。

已保存首次及最佳完整构造的routes、分工、job时刻和物理成绩；这些快照、采用的
全部阶段及最终结构反事实通过独立回放。其他提案只保存生产完整核验后的指标，
不声称对未存路线的指标独立逐事件审计。[runs](batch004/runs.json)、
[audit](batch004/audit.json)。

独立[载荷距离分解](geometry_diagnostics.json)发现：强解空载32.755km、
载1件187.019km、载2件359.458km；冷构造中继分别184.382／374.966／233.805km。
双载比例62.06%降到29.48%，空载比例5.65%升到23.25%，说明冷构造破坏了
原先的打包和访问交错。按载荷×航程，货物实际运输距离虽由905.935降至842.577
parcel-km，机队总航程仍明显增加；包裹路径缩短不等于飞行总成本下降。

后续重点保留既有取货与其他任务的路线布局：载货途中只交换等量一／两件包裹，
并调整对应交付点；另探索局部4任务联合重构和完整候选的短polish，避免每一步
都必须立即改善的局部障碍。所有新方法仍须在新批冻结后验证。

准时数。新界降低了这次机制搜索的工作量，不能据此声称完整求解端到端加速。
新math helper经多小例全局回放组件比较和1e−9期限边界测试验证，采用保守
1e−8min/1e−10km弱化；不用于自定义距离矩阵。
[manifest](batch013/manifest.json)、[runs](batch013/runs.json)、[audit](batch013/audit.json)。

几何界是无等待松弛下界；两路在各自接续点达到的最早时刻一般不能同时实现。
8192仍是有限预池，不能把剪枝解释为全局没有更好中继。下一批已在START前
准备匹配DIRECT/RELAY的交接后配送位置联合重构，继续用相同强checkpoint。
