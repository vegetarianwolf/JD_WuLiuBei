# 加权直送的周期整任务互换

在当前加权 ALNS 上增加一个有界的跨路线邻域，保持同一目标、官方完整输入和
240 秒端到端上限。主报告并列展示当前加权基线、首轮末端组合及本轮周期组合。
只有一个种子 `2026101461`，没有大规模测试或权重搜索。

## 实测结果

| 指标 | 共享加权基线 | 首轮末端组合 | 周期组合 |
| --- | ---: | ---: | ---: |
| 按时完成（项） | 129 | 129 | 132 |
| 按时率 | 64.5% | 64.5% | 66.0% |
| 逾期任务（项） | 71 | 71 | 68 |
| 总航程（km） | 596.128132 | 596.299323 | 602.410719 |
| 总逾期（min） | 2014.986775 | 2013.565034 | 2068.777963 |
| 加权 J | 0.482449586 | 0.482425134 | 0.479986582 |
| 端到端实测（s） | 238.917518 | 238.945662 | 238.957359 |

周期组合相对同一基线按时增加3项（+1.5个百分点），J下降0.5105%；与此同时
航程增加6.282586 km（+1.0539%），总逾期增加53.791188 min（+2.6696%）。
这是加权偏好下的取舍，不能称所有题目指标同时改善。三次均完成全部200单且在
240秒上限内，完整最终解通过独立核验。

周期共149次调用、2278个精确交换检查、25次动作内改善、175次完整规范检查，
累计耗时0.394205秒（已计入主搜索）。单次最大实测8.37675 ms；8 ms是检查截止
参数，原子评分和计时收尾可跨过该点，超时后的候选不保留。动作内改善不等于
后续ALNS接受或全局best更新。末端再接受2个交换，候选自身总逾期减少6.659813
分钟、航程减少0.413691 km，末端前后的局部收益不能代替最终基线对照。

## 算法差异

200 单、8 架机、每机累计至多 25 单且全部完成，使终局每机恰好 25 单。
原位交换两路线的完整请求（取件和送件两个标签一起交换），保持每条路线的
取送符号序列、每个前缀载荷和累计单数，可以调整分机并保留交错取送结构。
飞行时间仍会变化，因此两路线精确评价后必须完整规范核验。

首轮在原有至多 0.1 秒的末端预算中加入此邻域，并开启已有的 deadline/slack
惰性修复。其 J 仅改善约 0.005%，逾期项数不变、航程略增，记录原样保留于
`../weighted_method_improvement_20261014/`。本轮在该组合之上，把交换定期加入
主循环：每 120 次完整修复轮转一对路线，各路至多 4 个 anchor，最多精评 16 个
交换；单次预算至多 8 ms，且受主搜索 deadline 限制。代理只排序，不用正代理值
直接剔除候选。严格改善且在截止前完整核验的 checkpoint 才返回。

新候选进入原 ALNS 接受与奖励流程。周期 helper 不调用 RNG，但改变候选会自然
改变后续搜索轨迹，不能声称整个周期算法固定迭代等价。候选筛选属于启发式，
不保证找出全交换邻域最优。它适用于单件等载荷的 DIRECT，不把证明外推至中继。

固定研究目标沿用此前加权版：

```text
J = 0.50 × 逾期数 / 200
  + 0.25 × 总逾期分钟 / 4464.183540734935
  + 0.25 × 总航程公里 / 775.7731679286865
```

题目直接关注按时完成、航程和可控求解耗时。总逾期分钟是项目次级指标，J 为
研究搜索目标，不是官方综合评分；报告分别给出各物理指标，保留全部取舍。
核心生产默认仍为原词典序，新末端互换与惰性修复开关默认关闭；周期邻域只存在于
显式实验 context 中，正常退出或异常都会恢复被包装的修复函数。

## 共享基线与计时

`weighted_baseline` 的 row 和完整解逐字复制上一阶段实际有效运行，不再运行，
不改变其用时、配置或指纹，不计作新增独立样本。`weighted_periodic` 只新增一次
240 秒求解，使用同一初解、种子、权重、尺度、温度、候选上限及核心源码 ZIP。
新增差异仅为冻结的周期 helper 与执行器。两阶段共三个唯一有效运行：一个共享
基线、一个末端组合和一个周期组合，不计算多种子的均值或显著性。

计时包含读取、初解构造、搜索、末端强化、完整核验和解 JSON 写出，不含 Python
启动或导入；搜索扣除各自构造实测耗时和 1 秒收尾预留。交换从原预算内支出。
计时期间不运行测试、审计、图表渲染或额外优化。主机并非独占，墙钟与终值可能
受环境影响。本次小样本探索不支持稳定优势或某组成的独立因果结论。

首轮曾有一次优化器完成但记录器序列化失败，其完整解和原执行快照保存在
`../weighted_method_improvement_20261014/failed_recording/`。未落盘的精确用时
不补造，故障运行不纳入正式对照；只修复记录器后重新运行完整首轮。本次两阶段
累计四次优化器调用，其中三个有效记录、一次记录失败，未根据故障分数调参。
