# 当前加权算法的中继消融：相同预算的四方案对照

状态：12次求解和完整独立审计已完成，99项相关小型测试通过。按用户最新要求，
在报告生成之前停止；目前未生成HTML或图表。`runs.csv`保留12行实测，
`paired_summary.csv`保留6个配对，`summary.json`绑定原始记录与审计指纹。

本批检验论文中继扩展在当前算法和官方实例上的效果，不预设实验一定获胜。
所有运行前固定三个新种子 `2026101471/2026101472/2026101473`、四方案和顺序，
每次240秒端到端上限。全部12次顺序执行，不按中间结果更换种子、追加站点配置
或提前停止不利对照。主报告只用本批数据，不混历史不同预算、目标或源码的成绩。

## 四方案与归因

| 起点配置 | 禁用中继 | 允许中继 |
| --- | --- | --- |
| 8架均从原点出发 | `pure_direct` | `direct_relay` |
| 相同需求驱动预部署起点 | `direct_stations` | `direct_relay_stations` |

中继主效应分别在同一起点的两列之间配对。原点直送到预部署中继的差值混入起点
收益，不能称作中继独立收益。每对固定同样4站、选址seed42、候选站数2、绕行比
2.0、home坐标、DIRECT初解和求解种子。原点与预部署可有不同初解；同一起点内
指纹完全相同。站点和预部署均在运行前由全体任务几何确定，不用求解终值选址。

每方案都使用同一个当前源码ZIP和加权规则，DIRECT部分保留周期整任务互换、
末端互换和惰性修复；实际中继阶段跳过DIRECT周期动作。允许中继时使用现有
95%直送预热政策，剩余约12秒进行中继搜索，不测后修改比例或换另一个比例取优。
预热在含腿注册表的中继Problem上运行，具有额外计划索引和评价开销；因此不
假定它与独立DIRECT臂共享完全相同的搜索前缀。对照评价当前完整方案的同预算
效果，不能把每个差异都纯归因于某一个交接动作。

## 固定目标和题目指标

```text
J = 0.50 × 逾期任务数 / 200
  + 0.25 × 总逾期分钟 / 4464.183540734935
  + 0.25 × 总航程公里 / 775.7731679286865
```

四方案统一使用此前已冻结的原点DIRECT尺度，不按方案或终值重新归一化。
按时完成数/率、航程和实际求解耗时单独展示；总逾期用于解释迟到程度，J是研究
搜索偏好，不是题目官方综合分。按时数和航程可能发生取舍，完整保留各项结果。
论文现有正文仍描述词典序，本批是用户确认的新加权研究对照，不静默改写旧实验。

## 模型扩展边界

官方200单、8机、容量2、速度0.9 km/min，开放路线，全部完成且不计末单后返航。
论文中继扩展允许每任务使用一个固定站、同机或跨机两段运输，先卸货再取货，
包裹可在站暂存、飞机可能等待，无站库存上限，装卸时间为0。K25按最终交付
责任计数，入站转运不占额度；这与“每次实际搬运都计K”的可行域不同。
若把每次跨机搬运都占K且保持200=8×25，则根本没有额外转运额度。报告明示
采用的论文扩展，避免把结果包装为原题没有中继时的同一模型证明。

## 机制证据与独立检查

每个运行保留完整初解、DIRECT预热和中继阶段解（相应阶段存在时）、各自轨迹、
配置、预算与实际耗时；不能只凭中继自身优于较短预热，就称其胜过完整240秒直送。
最终解还生成一个不再求解的反事实：删除所有入站腿事件，将出站腿取/送替换为
该原任务取/送，保持末程责任与剩余访问顺序。该反事实仍需完整核验，并说明
其未重新优化、不是新的独立运行，也不替代正式DIRECT臂。

独立审计用官方CSV和冻结站点/腿/home，从头检查200单覆盖、取送、运输腿同机、
前缀载荷、最终责任K25、开放路线距离及交接DAG。它不调用生产评价器。
逐事件时刻通过路线飞行边及卸货→取货边传播；分别报告接收飞机等待和包裹在
站缓存时长、真实跨机交接数以及同机经站数，不把同机绕行当作跨机创新证据。

同预算配对、与预热自身的增量，以及固定结构反事实分别呈现。三个种子的结果
只描述本实例和当前配置，不能证明普遍最优、显著性或在所有任务分布上获益。
