# 截止期边界邻域与第一目标奖励：原题配对实验

[离线可视化报告](index.html) · [独立追加：较小邻域](compact_trial/README.md)

本批次延续原题，基线为提交 `32c2d6055d89e831f0e8b783d1cac5c2c750fb1c`
的默认算法。既有跨机 regret 的短长测反转只作为研究动机；本次重新运行同预算
基线，不使用历史成绩计算改善率。原题、官方数据、论文与 `final_*` 批次保持原样。

## 题目与历史依据

- 根目录 `命题1-低空经济场景下的物流无人机调度算法.docx`：优先保障更多任务按时，
  同时考核全部任务完成的总里程和分钟级求解。单机一般建议少于 120 秒，集群少于
  240 秒；本次集群长测总预算 240 秒，内部预留 1 秒收尾。
- `algorithm/deep-research-report (1).md`：开放式容量二取送货，采用
  `(逾期任务数, 总逾期分钟, 总航程)` 的项目词典序口径；总逾期分钟并非题目单列指标。
- `algorithm/OPTIMIZATION_UPDATE_2026-08-15.md`：常规移除比例 3%–8%、已有
  assignment_destroy 与局部评分加速的来由。
- 前两批 `optimization_20261013` 与 `regret_followup_20261013`：跨机 regret、
  位置回退和组合曾短测领先，但 240 秒确认退化。本轮不继续调同一 regret 分支。

## 用户选择与冻结协议

用户选择累计最多 45 分钟求解时间，覆盖 25 任务单机和 200 任务／8 架集群，
以集群为优化重点；先小测，有证据再扩大。进入确认后即使有一次退化也跑完四个
既定种子，以观察稳定性。仅在中长测均改善且无明显退化时才考虑改变默认算法。
报告先展示题目直接指标的前后对比，再展开逐种子与方法证据。

| 阶段 | 种子 | 每版本预算 | 晋级条件 |
| --- | --- | --- | --- |
| 单机决策核验 | 2026101371–73 | 固定 200 轮，上限 10 秒 | 路线、完整得分、原算子统计/权重、无时钟轨迹一致 |
| 初筛 | 2026101371–72 | 单机 5 秒；集群 10 秒 | 集群至少一胜且逾期数差合计不增加，单机不退化，固定轮数等价 |
| 中测 | 2026101381–83 | 单机 5 秒；集群 30 秒 | 集群至少两胜，每对逾期数不增加，单机不退化 |
| 确认 | 2026101321、2026101391–93 | 集群 240 秒 | 四对均不退化，三个新种子至少两胜 |

两个候选若均通过初筛，均进入中测。中测合格者按胜数、减少逾期的总数量、
逾期数相同情况下的胜数依次比较，完全并列优先较直接的边界邻域；只选一个
参加长测。`2026101321` 是历史反例压力复测，不能计作新的独立留出样本。

每次从读取 CSV 前计时，到独立完整评分和解 JSON 写出后结束；不含解释器
启动和模块导入。所有求解顺序执行，按种子交替版本顺序；三版本的第三个种子
轮换首位。总上限为 2700 秒，保留 60 秒核验余量，失败进程也计入预算。
两项机制在单机均不启用，因此单机使用固定轮数与短测检查，不重复单机长测。

## 两个独立候选

**A：截止期边界邻域**，`enable_boundary_destroy=True`。
保留原有 9 个破坏算子，另外加入 `deadline_boundary`。优先移除略微迟到且
从某一起点直接取送的下界仍允许按时的任务，随后考虑靠近截止期的按时任务。
先释放至少两条路线的任务槽，给满载集群中的跨机重分配留下空间。下界只能
排除个体不可能按时的任务，不能保证完整调度一定能救回该任务。

**B：第一目标奖励**，`enable_objective_rewards=True`。
接受准则、词典序评分和全局最优保留不变，只改变自适应算子的学习奖励：
减少全局／当前逾期数分别奖励 16／8，同逾期数下的全局／当前次级改善分别
奖励 2／1，等分或接受更差解奖励 0。最低权重仍保留探索机会。

两项开关彼此独立，旧 lazy、跨机 regret、位置回退、组合开关均关闭。
只在多机 DIRECT 搜索生效；实际 Relay 搜索阶段不启用。新增算子统计区分
第一目标改善、等分接受和完全相同路线的接受，作为机制诊断而非因果证明。

## 本批实际结果

39 次运行全部通过独立完整评分与预算审核，求解耗时 **376.306460 秒（6.27 分钟）**。
单机固定 200 轮的两个候选各 3 个配对全部决策等价，两个短预算阶段单机均平局。

| 集群阶段 | 基线逾期数 | 边界邻域 | 第一目标奖励 |
| --- | --- | --- | --- |
| 初筛 2026101371 | 77 | 73 | 75 |
| 初筛 2026101372 | 78 | 76 | 79 |
| 中测 2026101381 | 69 | 69（总逾期更高，词典序负） | 71 |
| 中测 2026101382 | 70 | 72 | 77 |
| 中测 2026101383 | 71 | 67 | 70 |

两候选均通过较宽松的探索初筛，但中测都只有 **1 胜 2 负**，并分别出现增加
逾期数的配对，因此未晋级、不启动长测，两项开关继续默认关闭。
边界邻域中测平均按时率为 65.33%，略高于基线 65.00%，但平均航程由
646.275 km 增至 653.394 km，且逐种子退化，不能仅凭平均按时率宣称优化成功。

用户在看到中测失败后选择继续尝试“缩小常规邻域”。因此新增独立的
`compact_trial/` 批次，绑定本批指纹，并与本批共享 45 分钟总求解预算。
这是明确记录的事后追加方向，不改写上述预定协议，也不把两批成绩混合。
追加较小邻域最终中测 0 胜 3 负，同样未晋级。父子合计 **65 次完整运行、
627.143594 秒（10.45 分钟）**，全部独立核验合法且预算内，未运行长测。
本轮三种尝试均未达到替换门槛，保留当前默认算法及 3%–8% 常规移除比例。

- `manifest.json`：固定协议、用户选择、输入与源码指纹。

- `acceptance_visual/`：父子报告桌面／360px、浅色／深色离线验收，含可重跑脚本、
  四张截图与浏览器记录；阶段、场景、候选、种子切换和曲线点击均已核验。

重新求解必须使用新目录，不覆盖已有记录：

```bash
PYTHONPATH=algorithm/src:. .venv/bin/python -m algorithm.experiments.run_objective_trials \
  prepare --output-dir algorithm/results/objective_trials_new
PYTHONPATH=algorithm/src:. .venv/bin/python -m algorithm.experiments.run_objective_trials \
  run --output-dir algorithm/results/objective_trials_new
```

只复算并重建本批报告，不运行新搜索：

```bash
PYTHONPATH=algorithm/src:. .venv/bin/python -m algorithm.experiments.audit_objective_trials \
  --output-dir algorithm/results/objective_trials_20261013
.venv/bin/python -m algorithm.experiments.render_objective_trials_report \
  --output-dir algorithm/results/objective_trials_20261013
```

实验结束后，工作树运行器补强了断点续跑：检查已保存解和快照指纹，发现
未登记的孤立解时拒绝覆盖。本次实际没有中止或孤立解；执行版本以
`sources/run_objective_trials.py` 为准，未修改其归档指纹。当前运行器不能直接
续跑这个旧执行版本的目录；重放旧批次应在独立检出中恢复归档脚本及 solver，
写入新目录。审计和报告重建可以直接使用以上命令。

固定墙钟预算受机器负载影响，相同种子未必逐位复现。每个种子以完整原始
三元组判胜；均值、样本标准差（ddof=1）只作描述，不是置信区间，也不是
显著性或普遍优势证明。单一官方实例与少量种子的结论不能外推到所有实例。
