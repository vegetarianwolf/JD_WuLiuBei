如何解释这次结果

原题直接考核按时任务数、完成全部任务的航程和求解时长。当前工程判优顺序为逾期任务数 → 总逾期分钟 → 航程；总逾期分钟是项目次级约定，因此“配对获胜”可能只改善该约定，而航程更长。

本轮研究扩展采用存储型接力：先在站点卸货，再由接手机取货，drop_time ≤ pickup_time；沿用论文的最终交付责任计入每机 K=25，前半程转运不占 K。AAAI 2014 文献的即时交接要求双方同时在场，与当前存储模型不同。

短预算、小样本只提供本实例的探索证据。三个新种子多数获胜是用户选择的采用门槛；没有显著性或最优性证明，也未验证分钟级与其他实例效果。求解时间从 CSV 读取前至完整核验和解写出后，不含 Python 启动和模块导入。

本轮三个独立候选与阶段决策

保留播种改善：播种耗尽阶段预算时，返回此前已完成且严格改善的 checkpoint。跨机候选多样性：在腿候选 beam 中为不同无人机保留最佳选项，减少同一架机的多个位置挤占全部候选。全局风险优先播种：依据完整全局时序，对原本按任务 ID 扫描的播种顺序进行风险排序。

三者分别测试，没有组合。主场景为需求驱动预部署 + 中继，次场景为原点起飞 + 中继；筛选允许任一有效配对获胜后扩大，只验证一个入围候选。DIRECT 固定 100 轮兼容检查只验证决策等价，不作为墙钟质量证据。
